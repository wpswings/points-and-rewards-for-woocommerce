## Image Specifications
- **Format**: WebP
- **Dimensions**: Recommended 800x400px or similar 2:1 aspect ratio
- **File Size**: Keep under 50KB for fast loading
- **Design Elements**: Should include campaign-specific imagery (sun/beach for Summer, lightning bolt for Flash, backpack/books for Back to School, crown/diamond for VIP)
- **Text**: Overlay should be readable with high contrast
- **Style**: Match existing template aesthetic (modern, clean, professional)

## Notes
- Use the color schemes specified above for consistent branding
- Ensure text is legible and conversion-focused
- Images should work well in both light and dark themes
- Consider adding subtle animations or effects for VIP templates to emphasize exclusivity

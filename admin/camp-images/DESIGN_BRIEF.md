## 📐 General Specifications

### Technical Requirements
- **Dimensions:** 800px × 400px (2:1 aspect ratio)
- **Format:** WebP (for web optimization)
- **File Size Target:** Under 50KB per image
- **Color Mode:** RGB
- **Quality:** High-resolution, web-optimized

### Design Guidelines
- **Typography:** Bold, modern sans-serif fonts (e.g., Montserrat, Poppins, Inter)
- **Text Color:** White with subtle shadow/outline for readability
- **Background:** Gradient (specified colors for each template)
- **Style:** Modern, eye-catching, conversion-focused
- **Elements:** Include subtle icons/graphics relevant to each campaign theme
- **Overlay:** Semi-transparent dark overlay (10-20% opacity) for text readability

## 🎨 Design Tips for All Templates

### Layout Structure
1. **Top Section:** Small category label (12-16px, uppercase, semi-transparent)
2. **Center Section:** Main heading (36-52px, bold, centered or left-aligned)
3. **Background:** Full gradient with subtle pattern/texture overlay
4. **Accents:** Icons or graphic elements (non-intrusive, support the message)

### Typography Guidelines
- **Heading Font:** Bold sans-serif (Montserrat Bold, Poppings Bold, Inter Bold)
- **Label Font:** Medium sans-serif, uppercase with letter-spacing
- **Text Shadow:** 0px 2px 4px rgba(0,0,0,0.3) for readability
- **Line Height:** 1.2-1.3 for headlines
- **Max Text Width:** 700px (leave 50px padding on sides)

### Visual Hierarchy
1. Gradient background (fills entire canvas)
2. Optional texture/pattern overlay (5-10% opacity)
3. Dark overlay for text area (10-20% opacity)
4. Graphic elements (icons, shapes - subtle, not overwhelming)
5. Text content (white with shadow/outline)

### Color Application
- Use exact hex codes provided
- Create smooth gradients (no harsh transitions)
- Add slight noise/grain for texture (1-2% opacity)
- Consider light overlay for depth

### File Export Settings
- **Format:** WebP
- **Quality:** 85-90%
- **Compression:** Lossy (for smaller file size)
- **Color Profile:** sRGB
- **Metadata:** Strip all metadata to reduce file size

## 🚀 Design Tools Recommendations

### Recommended Design Tools
1. **Figma** (Preferred - easy gradient control, WebP export plugin)
2. **Adobe Photoshop** (Professional - built-in WebP support)
3. **Canva Pro** (Quick - export PNG then convert to WebP)
4. **Affinity Designer** (Alternative to Photoshop)
5. **GIMP** (Free alternative with WebP plugin)

### WebP Conversion Tools
- **Squoosh.app** (Google's WebP converter - excellent quality/size balance)
- **CloudConvert.com** (Batch conversion)
- **ImageMagick** (Command-line: `convert input.png -quality 85 output.webp`)
